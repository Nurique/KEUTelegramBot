# KEU Bot — конструктор Telegram-бота

Визуальная настройка Telegram-бота Карагандинского университета Казпотребсоюза. Тексты бота и интерфейс админки поддерживают два языка: қазақша и русский.

## Быстрый старт

```bash
npm install
cp .env.example .env   # заполните BOT_TOKEN, ADMIN_PASSWORD, SESSION_SECRET
npm run dev            # админка: http://localhost:3000
npm run bot            # в отдельном терминале — сам бот
```

Нужен Node.js ≥ 22.5 (используется встроенный `node:sqlite`).

## Как работает

1. На схеме каждый **шаг** — это сообщение бота с текстом на двух языках и кнопками.
2. Кнопка либо открывает ссылку, либо ведёт на другой шаг. Связь рисуется перетаскиванием от точки справа от кнопки к шагу.
3. Шаг с меткой «Бастау/Старт» показывается после `/start` и выбора языка.
4. «Сақтау/Сохранить» записывает сценарий в БД, и бот сразу начинает его использовать.

Команды бота: `/start`, `/lang` (сменить язык).

## Деплой в Docker

Один образ, два сервиса: `admin` (админка, порт 3000) и `bot`. База SQLite лежит в томе `bot-data`.

```bash
# на сервере, в папке проекта
cp .env.example .env        # заполнить BOT_TOKEN, ADMIN_PASSWORD, SESSION_SECRET
docker compose up -d --build
docker compose logs -f bot  # проверить, что бот запустился
```

Админка слушает только `127.0.0.1:3000`. Наружу её публикуют через HTTPS-прокси, например Caddy (`/etc/caddy/Caddyfile`):

```
bot.example.kz {
    reverse_proxy 127.0.0.1:3000
}
```

Обновление: `git pull && docker compose up -d --build`.
Бэкап базы: `docker compose cp admin:/app/data/bot.db ./backup.db`.

Запускайте только один контейнер `bot` на один токен, иначе Telegram вернёт 409.
